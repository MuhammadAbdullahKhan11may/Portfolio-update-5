Project Overview

Academic IQ converts academic records into actionable planning information. A student can enter current CGPA, completed credit hours, target CGPA and upcoming semester credits, then use the system to understand the performance required to move toward that target.

The Problem

GPA Planning

Students often know their target CGPA but not the semester GPA required to reach it.

Performance Visibility

Academic results are easier to understand when performance data is presented clearly rather than as disconnected numbers.

Actionable Planning

Students need useful academic planning information instead of only seeing their current GPA.
