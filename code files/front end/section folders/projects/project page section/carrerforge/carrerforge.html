Project Overview

CareerForge models the complete recruitment lifecycle rather than functioning as a simple job-board interface. Students can discover opportunities, submit and manage applications, track interviews and manage their profiles, while recruiters have dedicated workflows for posting jobs, reviewing candidates, shortlisting applicants and managing interviews.

The Problem

Core Features

For Students

  • Browse jobs and internships
  • Create and manage profile
  • Submit and track applications
  • View interview schedules
  • Receive notifications
  • Manage account settings

For Recruiters

  • Post job listings
  • Manage active job postings
  • Review candidate applications
  • Shortlist candidates
  • Schedule/manage interviews
  • Access recruiter dashboard
