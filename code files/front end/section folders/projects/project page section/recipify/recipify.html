The Problem

Recipe Organization

Recipe collections can quickly become difficult to manage when ingredients, categories and cooking information are stored without a clear structure.

Efficient Retrieval

Users need fast ways to locate recipes by name or ingredient instead of manually scanning an entire collection.

Ingredient Planning

Comparing ingredients across recipes and preparing combined shopping requirements becomes difficult without structured set operations.

Key Engineering Work

Recipe Data Modeling

Structures recipe information, categories and ingredient collections for reusable operations.

Fast Recipe Search

Uses Hash Table lookup with Binary Search fallback for recipe retrieval.

Undo Delete

Uses stack-based behavior to restore recently deleted recipes.

Ingredient Set Operations

Uses union and intersection to calculate total and common ingredients.

Meal Planning

Connects recipes with an interactive calendar-based meal planning workflow.

Data Persistence

Supports saving recipe collections to JSON so data can be preserved and restored.
