Full-Stack Learning Management System

Project Overview

Eduvanta supports persistent application workflows for teachers and students through a backend API and relational database. Teachers manage courses, view enrolled students, record grades and review academic performance. Students access their enrolled courses, review grades, track performance and manage their profiles.
