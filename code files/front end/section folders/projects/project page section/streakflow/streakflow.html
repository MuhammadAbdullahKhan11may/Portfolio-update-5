StreakFlow

60-Day Coding Challenge & Progress Tracking Platform

StreakFlow is a challenge and progress-tracking platform designed to help developers build consistently over 60 days through daily tasks, streak tracking, progress visualization, and proof-of-work submissions.

Project Overview

StreakFlow turns a long-term coding challenge into a structured daily experience. Participants can work through development tasks, record completion, maintain a streak, monitor weekly and monthly progress, and attach proof of work such as GitHub repositories or LinkedIn posts. The platform focuses on consistency rather than isolated coding sessions, giving users visible progress throughout a 60-day challenge.

The Problem

Consistency

Learning development skills requires repeated practice, but maintaining daily momentum over several weeks can be difficult.

Accountability

Completing tasks is more meaningful when progress can be recorded and supported with visible proof of work.

Progress Visibility

Developers need a clear way to understand streaks, weekly activity, completion rate and long-term challenge progress.

Progress & Accountability System

Tracks consecutive challenge activity and gives users an immediate consistency indicator.

Longest Streak

Preserves the user's best streak as a longer-term consistency milestone.

Completion Rate

Shows how much of the challenge has been completed over time.

Proof of Work

Allows users to associate completed challenges with GitHub and LinkedIn evidence.
